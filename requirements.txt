# ============================
# AI Text Summarization System
# Python Dependencies
# ============================
#
# 📚 WHAT IS requirements.txt?
#     This file lists every external Python package the project needs.
#     When someone clones your repo, they run:
#         pip install -r requirements.txt
#     and ALL dependencies install automatically.
#
# 📚 WHY PIN VERSIONS? (e.g., streamlit>=1.30.0)
#     Without version pins, pip installs the latest version — which might
#     introduce breaking changes. We use >= (minimum version) to balance
#     stability with flexibility.
#
# ============================
# CORE FRAMEWORK
# ============================

# Streamlit: Turns Python scripts into interactive web apps.
# No HTML/CSS/JS needed — just Python. Perfect for ML demos.

# ============================
# NLP & AI MODELS
# ============================

# Handles tensor operations, GPU acceleration, model inference.

# We use it for: sentence tokenization, stopwords, stemming, BLEU score.

# spaCy: Industrial-strength NLP library.
# We use it for: NER (Named Entity Recognition), lemmatization, POS tagging.

# scikit-learn: Machine learning library.

# FILE PROCESSING
# ============================

# PDFs don't store "plain text" — they store positioning commands. PyPDF2 decodes them.
